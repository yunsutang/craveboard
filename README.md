# Recipe Board

A visual, personal recipe library for saving recipes from TikTok and Instagram. This first version is a static Vercel-ready prototype with browser-local storage, so it can evolve into a real app later.

## Run locally

```bash
npm run dev
```

Then open the local URL shown by `serve`.

## Deploy

Import this folder into Vercel, or connect the GitHub repository once created. No build command is required.
